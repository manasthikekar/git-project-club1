# Manas | Developer Card

A modern, responsive personal developer card featuring a stunning **glassmorphism** UI style. Built entirely with HTML and Tailwind CSS, this project showcases a frosted glass panel floating over animated, vibrant background shapes.

## ✨ Features

*   **Glassmorphism UI:** Implements blurred backgrounds (`backdrop-filter`) and semi-transparent borders to create a realistic frosted glass effect.
*   **Animated Background:** Custom CSS keyframe animations (blob effects) for dynamic, moving color blobs behind the main card.
*   **Responsive Design:** Fully mobile-friendly layout that scales perfectly across devices.
*   **Zero Dependencies:** Uses Tailwind CSS via CDN—no build steps or package managers required.
*   **Single-File Setup:** All HTML, CSS, and configuration are neatly contained in a single `index.html` file.

## 🚀 Technologies Used

*   **HTML5**
*   **Tailwind CSS** (via CDN for styling, utilities, and layout)
*   **Custom CSS** (for precise keyframe animations and webkit backdrop filters)

## 🛠️ How to Use

Since this project requires no build tools, running it is incredibly simple:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Double-click the `index.html` file to open it in your default web browser, or serve it using a local development server (like VS Code's Live Server extension).

## 🎨 Customization

You can easily customize this card to fit your own profile:
*   **Colors:** Modify the Tailwind color classes (e.g., `bg-pink-500`, `bg-orange-500`) in the floating shape `div`s to change the background palette.
*   **Text & Links:** Update the `h1`, `p`, and `href` attributes in the action buttons to reflect your personal information and portfolio links.
*   **Skills:** Edit the glass pills in the "Core Skills" section to showcase your specific tech stack.
